앱을 삭제하거나 Safari 웹사이트 데이터를 지우지 마세요. 먼저 가능한 경우 기록을 파일로 백업하고, 파일 앱에 실제 저장됐는지 확인해 주세요.

문의에는 사용 중인 버전(iOS 앱 / 웹앱), iOS 버전, 문제가 생긴 단계와 오류 문구를 적어 주세요. 감정 메모나 백업 파일, 비밀번호는 보내지 않아도 됩니다. 화면을 보낼 때는 개인 내용을 가려 주세요.

iOS 앱 도움말

기록은 어디에 저장되나요?

감정과 메모는 기기의 앱 전용 공간에 저장됩니다. 운영자가 기록을 조회하는 기능이나 자동 클라우드 동기화는 없습니다. 앱 삭제·기기 분실·교체 전에 백업하세요. 자동 기기 백업 대상에서 제외되므로 파일 백업을 따로 보관해 주세요.

백업하고 다시 가져오려면?

오늘 → 사용 안내 → 설정 · 백업 · 개인정보로 이동하세요. 기록 화면 아래의 기록 관리 메뉴에서도 설정으로 들어갈 수 있어요.

  1. ‘기록을 JSON 파일로 내보내기’를 누르고 저장 위치를 고르세요.
  2. 기기에만 보관하려면 ‘나의 iPhone’을 선택하고 파일 앱에서 저장을 확인하세요.
  3. ‘앱·웹앱 JSON 기록 가져오기’에서 파일을 선택하세요. 기존 기록을 유지하고 중복은 건너뜁니다.

백업은 암호화되지 않으며 감정과 메모를 포함합니다. iCloud Drive 등으로 저장하면 해당 서비스에 보관됩니다. iOS 파일은 20MB, 웹앱에서 만든 파일은 5MB·10,000건 한도입니다.

웹앱에서 사용하던 기록을 옮길 수 있나요?

웹앱에서 JSON 파일로 백업한 뒤 iOS 앱 설정에서 가져오세요. 자동으로 동기화되지는 않습니다. 지원하지 않는 형식은 가져오기를 중단하며 기존 기록은 유지합니다. iOS 앱 백업을 웹앱으로 가져오는 역방향 이동은 지원하지 않습니다.

AI 요약이 보이지 않아요

기기 내 AI는 iOS 26 이상에서 지원 기기·모델 준비 상태·한국어 지원 조건을 충족해야 사용할 수 있어요. 선택한 기간에 3일 이상·5개 이상의 기록도 필요합니다. 지원되지 않아도 감정카드·기록·기본 통계·성찰 질문은 사용할 수 있어요.

기록을 읽지 못하거나 저장에 실패했어요

앱을 삭제하지 말고 오류 문구를 확인하세요. 기기 잠금을 해제한 상태인지, 저장 공간이 충분한지 확인해 주세요. 기존 파일에 문제가 있으면 앱은 덮어쓰기를 중단합니다. 운영자는 기기 기록을 원격으로 복구할 수 없습니다.

계정을 삭제하거나 기록을 지우려면?

회원가입이 없어 탈퇴할 계정은 없습니다. 기록 상세에서 개별 삭제하거나 설정의 ‘기기 내 모든 기록 삭제’를 사용할 수 있어요. 삭제한 기록은 백업이 있어야 복원할 수 있습니다. 외부로 내보낸 파일은 별도로 관리하세요.

홈 화면 웹앱 도움말

웹앱의 오늘 → 사용 안내에서 설치 방법, 업데이트 방법, 아이폰 테스트 체크리스트를 볼 수 있어요.

업데이트해도 기록을 유지하려면?
  1. 기록 → 기록 관리 · 백업과 복원에서 먼저 파일로 백업하세요.
  2. 인터넷에 연결해 홈 화면 앱을 열고 잠시 기다리세요.
  3. 앱을 완전히 닫은 뒤 같은 홈 화면 아이콘으로 다시 열고 기존 기록을 확인하세요.

업데이트를 위해 앱이나 Safari 데이터를 삭제하지 마세요. Safari와 홈 화면 앱의 기록은 자동으로 동기화되지 않을 수 있습니다.

인터넷 없이 사용할 수 있나요?

처음 인터넷에 연결해 열고 ‘오프라인 사용 준비 완료’를 확인한 뒤에는 감정카드와 기록 저장·조회, 기본 통계, 파일 백업을 사용할 수 있어요. 외부 링크와 새 업데이트에는 인터넷이 필요합니다. 웹앱에는 생성형 AI 기능이 없습니다.
