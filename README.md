# 오늘감정카드 개인정보 처리방침

시행일: 2026-10-19

공개 URL: https://ham2748.github.io/oneul-emotion-card-privacy/

## 1. 기본 원칙

오늘감정카드는 회원가입 없이 사용하는 감정 기록 앱입니다. 운영자는 앱을 통해 사용자의 감정 기록, 메모, 이름, 이메일, 전화번호, 위치 또는 광고 식별자를 수집하거나 서버로 전송하지 않습니다. 광고, 사용자 추적, 원격 사용 분석 SDK 및 원격 AI API를 사용하지 않습니다.

## 2. 기기 안에서 처리하는 정보와 목적

사용자가 입력한 감정 종류, 세부 감정, 감정 강도, 상황, 메모와 기록 시각, 기록 구분용 임의 ID를 기기 내 앱 전용 공간에 저장합니다. 이 정보는 기록 조회, 통계, 성찰 질문 및 사용자가 요청한 감정 요약에 사용합니다. 기록 구분용 ID는 사용자 추적에 사용하지 않습니다. 운영자는 기기에 저장된 기록을 열람할 수 없습니다.

## 3. 온디바이스 분석

통계는 기기 안에서 계산합니다. 지원 기기에서 사용자가 AI 분석을 요청하면 Apple의 기기 내 시스템 언어 모델이 선택 기간의 기록 일부를 처리합니다. 앱은 해당 기록을 운영자 서버나 외부 AI 서버로 보내지 않으며, 운영자가 모델 학습을 위해 수집하지 않습니다. AI 요약은 의료 진단이나 치료를 위한 정보가 아닙니다.

## 4. 보관과 보호

기록은 사용자가 삭제할 때까지 앱 전용 저장 공간에 보관하고 iOS 데이터 보호를 적용합니다. 기록 저장 폴더는 자동 기기 백업 대상에서 제외하도록 설정합니다. 자동 클라우드 동기화는 제공하지 않습니다. 앱 삭제, 기기 분실 또는 교체 시 기록을 잃을 수 있으며 운영자는 이를 복구할 수 없습니다.

## 5. 내보내기와 가져오기

사용자가 직접 요청한 경우에만 기록을 JSON 파일로 내보내거나 선택한 JSON 파일을 가져옵니다. 내보낸 파일은 암호화되어 있지 않으며 감정 기록과 메모가 포함됩니다. 사용자가 클라우드 저장소나 다른 앱을 저장·공유 대상으로 선택하면 그 서비스의 정책이 적용됩니다. 앱 안에서 기록을 삭제해도 외부로 내보낸 사본은 삭제되지 않으므로 사용자가 별도로 관리해야 합니다.

## 6. 삭제와 이용자의 선택

기록 화면에서 개별 기록을 삭제하거나 설정의 ‘기기 내 모든 기록 삭제’를 사용할 수 있습니다. 기록 내보내기와 가져오기도 설정에서 이용할 수 있습니다. 계정과 서버 저장 데이터가 없어 별도의 회원 탈퇴 절차가 없습니다.

## 7. 외부 서비스와 웹페이지

앱은 감정 기록을 제3자에게 제공하거나 판매하지 않습니다. 사용자가 연구 자료 또는 공개 개인정보 처리방침 링크를 열면 외부 웹사이트에 접속합니다. 이때 해당 웹사이트와 호스팅 제공자는 웹 요청 처리와 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있으며 각 서비스의 정책이 적용됩니다. 외부 링크에 감정 기록이나 메모를 포함하지 않습니다. 앱 다운로드 및 운영체제 자체의 정보 처리는 Apple의 정책에 따릅니다.
