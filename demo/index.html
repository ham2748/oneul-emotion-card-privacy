기존 기록을 지키려면 백업부터 해 주세요. 앱이나 Safari 웹사이트 데이터를 지우지 마세요. 실제 확인한 항목만 체크하세요.

기본 마음 분석 확인 · iPhone 11 Pro

기존 기록으로 확인할 수 있어요. 기본 요약은 기기에서 집계하며, 생성형 AI가 아니에요. 아래 항목은 실제 확인한 뒤 체크하세요.

문제가 생기면 중단하고 백업을 보관하세요. 개인 메모나 백업 파일을 보내지 말고 문제 단계와 오류 문구만 알려주세요.

체크 상태는 이 기기에만 저장되며 감정 기록 백업에는 포함되지 않아요.

홈 화면에서 앱처럼

오프라인 사용 준비를 확인하고 있어요.

  1. 기존 기록이 있다면 먼저 기록 → 기록 관리 · 백업과 복원 → 기록 파일로 백업하기로 파일을 저장하세요.
  2. Safari의 공유 → 홈 화면에 추가를 누르세요. 웹 앱으로 열기 옵션이 보이면 켠 뒤 추가하세요.
  3. 인터넷에 연결된 상태에서 홈 화면의 오늘감정카드 아이콘을 한 번 열고, 오프라인 사용 준비 완료 안내를 기다리세요.
  4. 기존 기록이 보이지 않으면 기록 → 기록 관리 · 백업과 복원 → 백업 파일 가져오기로 복원하세요. Safari와 홈 화면 앱의 기록은 자동으로 동기화되지 않을 수 있어요.
  5. 이후에는 인터넷 없이도 감정카드, 기록 저장·조회, 통계와 백업을 사용할 수 있어요.

기존 기록을 지키며 업데이트하기

업데이트 전, 먼저 기록을 파일로 백업해 주세요. 기록은 이 기기에 저장되어 있으므로 백업 파일을 따로 보관하면 안심할 수 있어요.

  1. 기록 → 기록 관리 · 백업과 복원 → 기록 파일로 백업하기에서 파일을 저장하세요.
  2. 비행기 모드를 끄고 Wi-Fi나 모바일 데이터에 연결하세요.
  3. 홈 화면의 오늘감정카드를 열고 잠시 기다리세요. 새 화면 파일을 내려받습니다.
  4. 앱 전환 화면에서 오늘감정카드를 위로 밀어 완전히 닫은 뒤, 같은 홈 화면 아이콘으로 다시 여세요. 이전 화면이 남아 있으면 한 번 더 반복하세요.
  5. 새 화면과 기존 기록이 보이는지 확인하세요. 기록이 안 보이면 같은 홈 화면 앱인지 먼저 확인하고, 저장한 백업 파일을 가져오세요.

업데이트하려고 앱을 삭제하거나 Safari의 방문 기록·웹사이트 데이터를 지우지 마세요. 기록이 사라질 수 있어요. 일반 업데이트는 화면 파일만 바꾸고 기기에 저장한 기록은 유지합니다.

내 기록은 어디에 있나요?

감정과 메모는 이 기기에만 저장됩니다. 운영자나 다른 사용자에게 전송되지 않아요. Safari와 홈 화면 앱 사이의 기록 이동은 파일 백업을 이용하세요.

앱이나 웹사이트 데이터를 삭제하면 기록을 잃을 수 있어요. 기록 메뉴에서 정기적으로 백업해 주세요. 백업 파일을 다른 사람에게 보내면 그 사람이 내용을 볼 수 있어요.

처음 준비와 업데이트에는 인터넷이 필요합니다. 공개 개인정보 처리방침은 인터넷 연결 후 볼 수 있어요.

기록 백업과 복원

백업 파일은 암호화되지 않으며 감정과 메모가 포함됩니다. 서버에 업로드하지 않습니다. iCloud Drive 등을 선택하면 해당 서비스에 파일이 저장될 수 있어요.

브라우저 데모 전용 JSON 백업 · 기존 기록을 유지하고 중복은 건너뜁니다.

아이폰 Safari에서 백업·가져오는 방법

비용 없이, 기록을 서버에 보내지 않고 파일로 보관하고 복원할 수 있어요.

1. 저장 위치 정하기 · 처음 한 번

  1. 아이폰 설정 → 앱 → Safari → 다운로드를 여세요. iOS 버전에 따라 설정에서 Safari로 바로 들어갈 수 있어요.
  2. 나의 iPhone을 선택하세요. iCloud Drive를 선택하면 해당 클라우드에도 파일이 저장될 수 있어요.

2. 기록을 파일로 백업하기

  1. 이 화면에서 기록 파일로 백업하기를 누르고 안내를 확인하세요.
  2. 다운로드 확인창이 나오면 다운로드를 누르세요. 파일 미리보기가 열리면 공유 메뉴의 파일에 저장으로 저장하세요.
  3. 파일 앱 → 둘러보기 → 나의 iPhone → 다운로드에서 oneul-emotion-card-날짜.json 파일이 있는지 확인하세요. 다른 폴더에 저장했다면 그 폴더를 확인하세요.

백업 파일이 실제로 저장됐는지 확인하기 전에는 Safari 데이터를 지우지 마세요.

3. 백업 파일 다시 가져오기

  1. 이 데모의 기록 → 기록 관리 · 백업과 복원 → 백업 파일 가져오기를 누르세요.
  2. 파일 선택 화면에서 둘러보기 → 나의 iPhone → 다운로드로 이동해 저장한 .json 파일을 선택하세요.
  3. 추가할 기록 수를 확인하고 확인을 누르세요.
  4. 가져오기 완료 문구와 기록 목록을 확인하세요.

기존 기록은 유지하고 동일한 기록은 건너뜁니다. Safari 데이터를 지우지 않은 상태에서도 가져오기를 시험할 수 있어요.

백업에는 저장한 시점까지의 기록만 담겨요. 새 기록이 쌓이면 다시 백업해 주세요. 파일은 암호화되지 않으며 감정과 메모가 포함되니 안전하게 보관하세요. 이 파일은 브라우저 데모 전용입니다.
